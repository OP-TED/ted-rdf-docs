# Contributing

This documentation is maintained by the TED Open Data team at the [Publications Office of the EU](https://op.europa.eu/). Contributions and corrections from the community are welcome.

## How to contribute

1. Fork the repository or create a branch from `develop`
2. Make your changes
3. Open a pull request targeting the `develop` branch
4. Your changes will be reviewed by the team and published with the next release (when `develop` is merged to `main`)

Please discuss significant changes via a [GitHub issue](https://github.com/OP-TED/ted-rdf-docs/issues) before starting work.

## Contributing to the Query Library

The Query Library has moved to its own dedicated repository: [OP-TED/ted-open-data-examples](https://github.com/OP-TED/ted-open-data-examples).

To contribute queries, please visit that repository and follow its [contributing guide](https://github.com/OP-TED/ted-open-data-examples/blob/main/CONTRIBUTING.md).
