= Contributing to the Query Library
:doctitle: Contributing to the Query Library

The Query Library provides example SPARQL queries that are displayed in the https://data.ted.europa.eu/[TED Open Data Service]. Contributions from the community are welcome.

NOTE: The Query Library has moved to its own repository: https://github.com/OP-TED/ted-open-data-examples[OP-TED/ted-open-data-examples]. Please submit contributions there.

== How you can help

* *Add comments* to existing queries to make them easier to understand
* *Fix or improve* existing queries (e.g. adding explicit joins for better performance)
* *Contribute new queries* that demonstrate useful data retrieval patterns

== How to contribute

. Create a branch from `develop` in the https://github.com/OP-TED/ted-open-data-examples[ted-open-data-examples] repository
. Add or edit `.sparql` files in the https://github.com/OP-TED/ted-open-data-examples/tree/main/queries[queries directory]
. Update `web-library.yaml` if adding a new query (with category, title, and description)
. Test your query on the https://data.ted.europa.eu/[TED Open Data Service]
. Open a pull request targeting `develop`

Your changes will be published with the next release.

== Writing guidelines

For detailed instructions on query format, commenting conventions, prefix usage, and best practices, see the https://github.com/OP-TED/ted-open-data-examples/blob/main/CONTRIBUTING.md[Query Library contributing guide].
